# Heart Disease Prediction using KNN

## Overview
Today I learned and compared different machine learning classification algorithms including Logistic Regression, KNN, Decision Tree, SVM, and Naive Bayes using a heart disease dataset.

After comparing their performance, the best-performing model was selected and deployed as a **Streamlit web application**. This project uses the **K-Nearest Neighbors (KNN)** model to predict the risk of heart disease based on user-provided health information.

## Features
- Interactive Streamlit web application
- Predicts heart disease risk probability
- Uses a trained KNN classification model
- Displays risk percentage with personalized risk-level messages
- Handles preprocessing using saved scaler and feature columns
